# Données initiales

Le fichier `lei.sql` (non versionné, voir `.gitignore`) crée le foyer, ses deux membres,
le profil de Leï, sa vitamine D et l’historique repris de la première version de l’appli.

1. Remplacez les deux adresses e-mail en haut du fichier.
2. Exécutez-le une seule fois, après la migration, dans Supabase > SQL Editor.

Les données d’un enfant n’ont rien à faire dans un dépôt Git, même privé :
une fois versionné, ce dossier ne contient que ce mode d’emploi.
